# Exploratory Testing Charters (Session-Based)

Each session is time-boxed to 45 minutes. Findings are logged as defects or new test cases.

| # | Charter | Focus / Heuristic |
|---|---|---|
| 1 | Explore **role-based access** as an ESS user with direct URLs to discover privilege escalation | Security/RBAC |
| 2 | Explore **leave calculations** around weekends, holidays and half days | Business rules |
| 3 | Explore **file uploads** (photo, resume, attachments) with odd types and sizes | Input validation |
| 4 | Explore **candidate workflow** by skipping and reversing stages | State transitions |
